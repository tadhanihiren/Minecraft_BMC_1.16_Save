# Minecraft BMC 1.16 Save

Modded Minecraft 1.16 world save from the Better Minecraft modpack.

## Modpack

Better Minecraft (BMC) 1.16

## How to Use

1. Download this repository
2. Extract the `golida` folder
3. Copy it to your Minecraft saves folder:
   - **Windows:** `%appdata%\.minecraft\saves`
   - **Linux:** `~/.minecraft/saves`
   - **Mac:** `~/Library/Application Support/minecraft/saves`
4. Launch Minecraft and load the world
